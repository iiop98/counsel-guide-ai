상담 길잡이 AI

시연 버전 · 샘플 데이터

상담 내용을 입력하면 생애 사건을 인식하고, 필요한 제도와 근거, 추가 확인 질문, 신청 순서 로드맵을 한 화면에 띄워 줍니다. 최종 자격 판단은 담당 공무원이 합니다.

① 상담 내용 입력 예시를 눌러 바로 시연할 수 있어요

  1. 상담 이해사건·가구 정보 추출
  2. 제도 검색복지서비스 데이터 조회
  3. 근거 대조지원대상·선정기준 확인
  4. 로드맵 생성순서·서류·연계 기관

② 인식된 사건과 파악된 정보

③ 지금 확인하면 좋은 질문 빠진 정보를 AI가 찾아 줍니다

④ 사건 기반 로드맵 무엇을 어떤 순서로 할지

⑤ 추천 제도와 근거 모든 추천에 원문 근거를 붙입니다

※ 이 안내는 참고용입니다. 자격 여부와 지급액은 담당 공무원이 소득·재산 조사 후 최종 확인합니다. 샘플 데이터의 세부 기준은 시연용 요약이며, 실제 연동 시에는 복지서비스 API 원문으로 대체됩니다.
