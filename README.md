# 상담 길잡이 AI 시연 프로젝트

복지 상담 중 내담자의 말에서 **생애 사건을 인식**하고, 필요한 제도와 근거, 추가 확인 질문, **신청 순서 로드맵**, 쉬운 말 안내문을 한 화면에 보여 주는 공무원용 도구의 시연 버전입니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 시연 화면. 파일만 열어도 동작하며, 샘플 데이터와 규칙 기반 사건 인식을 사용 |
| `server/server.js` | 실데이터 연동용 서버. 복지서비스 API 호출 + LLM 사건 분석·제도 선별 |

## 1. 화면만 시연할 때 (발표 기본)

`index.html`을 브라우저에서 열고 위쪽 예시 버튼(실직+출산+월세 체납 / 어르신 퇴원 후 돌봄 / 한부모 가정)을 누르면 됩니다.
시연용 샘플 제도는 복지서비스 API 항목(지원대상·선정기준·지원내용·신청방법·문의처) 형식에 맞춘 요약이며, `기초연금`만 복지로 원문 기준입니다. 화면에도 이 점이 표시됩니다.

### Vercel에 공개하기

`index.html` 한 파일만 넣은 새 폴더에서 `npx vercel --prod`를 실행합니다. **인증키는 절대 `index.html`에 넣지 마세요.** 공개 페이지입니다.

## 2. 실데이터로 연결할 때

1. 공공데이터포털에서 API 활용신청 후 인증키를 받습니다.
   - 한국사회보장정보원_중앙부처복지서비스: https://www.data.go.kr/data/15090532/openapi.do
   - 지자체복지서비스 (같은 기관의 지자체 목록·상세 API)
2. `server/.env.example`을 `.env`로 복사해 키를 채웁니다. `.env`는 GitHub에 올리지 않습니다.
3. 실행

   ```bash
   cd server
   npm install
   npm start
   ```
4. 브라우저에서 `http://localhost:3000` → 분석 방식을 **서버 연결**로 선택

### 확인 상태

- **중앙부처 목록조회:** 실제 응답으로 확인 완료. `servId`, `servNm`, `jurMnofNm`, `jurOrgNm`, `servDgst`, `lifeArray`, `trgterIndvdlArray`, `intrsThemaArray`, `srvPvsnNm`, `sprtCycNm`, `rprsCtadr`, `servDtlLink` 필드를 사용합니다.
- **중앙부처 상세조회:** 실제 응답을 아직 확인하지 못했습니다. 지원대상·선정기준·신청방법 필드명이 추정이므로, `http://localhost:3000/api/debug/central-detail?id=WLF00000024` 로 응답을 확인한 뒤 `normalize()`의 필드명을 맞추세요. 필드가 맞지 않아도 목록 정보만으로 카드가 만들어지고 "상세 화면에서 선정기준을 확인하세요"로 표시됩니다.
- **지자체 API:** 주소를 활용가이드로 확인해야 합니다. 실패하면 중앙부처 결과만 사용합니다.
- 서버 연결 모드가 실패하면 화면이 자동으로 데모 방식으로 돌아갑니다.

## 개인정보

- 시연에는 **가상 사례만** 사용하세요. 실제 상담 내용을 외부 LLM으로 보내지 않습니다.
- 실제 도입 시에는 비식별 처리, 저장 최소화, 내부망 운영이 전제됩니다. (기획서에 같은 내용을 적어 두세요.)

## 발표 시연 흐름 제안 (3분)

1. 예시 1(실직+출산+월세 체납)을 누른다 → 인식된 사건과 파악된 가구 정보를 보여 준다
2. "빠진 정보를 AI가 되묻는다" → ③ 질문 목록 설명
3. ④ 로드맵에서 "무엇을 어떤 순서로" 설명, 한 번에 준비할 서류 강조
4. ⑤ 제도 카드에서 지원대상·선정기준 **원문 근거**와 "확인 필요" 표시 설명 (최종 판단은 공무원)
5. ⑥ 안내문 복사로 내담자 전달 장면 마무리
